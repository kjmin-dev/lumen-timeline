Lumen Timeline is currently developed in a workspace repository while milestone 6 validates the first npm release. All eight packages are written in strict TypeScript, compiled by [tsrs](https://github.com/oxc-project/tsrs) into ES modules with declarations, and tested directly against both source and build outputs.

## Clone and build

Requires Node 26 (see `.node-version`).

```sh
git clone https://github.com/kjmin-dev/lumen-timeline && cd lumen-timeline
npm ci
npm run check
```

`npm ci` links the workspaces and runs `tsrs -b` to emit each package's `dist/`. `npm run check` runs formatting (`oxfmt`), type-aware linting (`oxlint`), compilation, unit tests against both source and build, `tsrs`/`tsc` parity, public API snapshot verification and Markdown link checks.

## Run the interactive examples

```sh
npm run example:vanilla
```

Open the printed local address to explore three runnable workspaces with zero remote dependencies:

- **Video dubbing workspace** (`/examples/vanilla/index.html`) — reference video, speaker tracks, bilingual line list with line play, candidate take auditioning, waveforms and a simulated take generator.
- **Audio-only workspace** (`/examples/vanilla/audio.html`) — audio output clock, overlapping tracks, saved markers and marker-crossing announcements.
- **Shared sessions** (`/examples/sync/index.html`) — open in multiple tabs to watch `@lumen-timeline/sync` converge edits over `BroadcastChannel` with automatic Web Lock leader handover.

## Minimal integration

The host creates what every view shares once, in a module of its own: the editor, the `AudioContext`, the stream catalog, the buffer resolver and the transport. Later guides import these from `./host.js`.

```js title="host.js"
import { createEditor, unitsToTicks } from "@lumen-timeline/core";
import { createAudioTransport } from "@lumen-timeline/media";

export const sec = (n) => unitsToTicks(n, 1);

// The document: one track, one line with two recorded takes, and a marker in the line.
export const editor = createEditor({
  project: {
    schemaVersion: 1,
    duration: sec(30),
    tracks: [{ id: "voice", name: "Voice", overlap: "exclusive" }],
    clips: [
      {
        id: "line-1",
        name: "Opening line",
        trackId: "voice",
        kind: "audio",
        start: sec(2),
        duration: sec(4),
        contentIn: 0,
        takeIds: ["take-a", "take-b"],
        activeTakeId: "take-a",
      },
    ],
    takes: [
      {
        id: "take-a",
        label: "Take 1",
        assetId: "voice-a",
        streamId: "mono",
        sourceAtContentZero: 0,
      },
      {
        id: "take-b",
        label: "Take 2",
        assetId: "voice-b",
        streamId: "mono",
        sourceAtContentZero: 0,
      },
    ],
    markers: [{ id: "breath", start: sec(4), label: "Breath" }],
  },
});

// One AudioContext for the page; it starts on the first play.
export const context = new AudioContext({ sampleRate: 48000 });

// What the planner needs to know about the decoded audio behind each take.
const mono = { assetVersion: 1, sampleRate: 48000, availableStart: 0, availableEnd: 48000 * 4 };
export const catalog = { version: 1, streams: { "voice-a": { mono }, "voice-b": { mono } } };

// Decodes each asset once, the first time a voice or a waveform needs it.
const decoded = new Map();
export function decode(assetId) {
  if (!decoded.has(assetId))
    decoded.set(
      assetId,
      fetch(`/media/${assetId}.opus`)
        .then((response) => response.arrayBuffer())
        .then((bytes) => context.decodeAudioData(bytes)),
    );
  return decoded.get(assetId);
}
export const resolveBuffer = (span) => decode(span.assetId);

// Plays the editor's document through Web Audio. It lives as long as the page.
export const transport = createAudioTransport({ editor, context, catalog, resolveBuffer });
```

Then mount the view in vanilla JavaScript, or through the [React](/frameworks/react/), [Svelte](/frameworks/svelte/), [SolidJS](/frameworks/solid/) or [Vue](/frameworks/vue/) wrapper. Each tab is a whole file. A wrapper never creates or disposes the editor or the transport, and the button dispatches to the same editor the view edits. The tab you pick is kept on every page of this site:

```js title="main.js"
import { commands } from "@lumen-timeline/core";
import { mountTimeline } from "@lumen-timeline/timeline";
import "@lumen-timeline/timeline/style.css";
import { editor, sec, transport } from "./host.js";

// The page holds <button id="split">Split at 4 s</button> and <div id="timeline"></div>.
const view = mountTimeline(document.querySelector("#timeline"), { editor, transport });

document.querySelector("#split").addEventListener("click", () => {
  editor.dispatch(commands.splitClip({ clipId: "line-1", at: sec(4) }));
});
```
